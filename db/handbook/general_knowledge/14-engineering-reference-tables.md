## Rumus Cepat

| Kebutuhan | Rumus |
|---|---|
| Tekanan hidrostatik (psi) | 0,052 × berat fluida (ppg) × TVD (ft) |
| Faktor buoyancy | 1 − (berat fluida (ppg) / 65,5) |
| Berat kill fluid (ppg) | SF + 8,33 + [tekanan shut-in / (0,052 × TVD top perforation)] |
| Pencampuran dua fluida | V1 × MW1 + V2 × MW2 = (V1 + V2) × MW3 |
| Compression ratio pompa | (swept + unswept volume) / unswept volume |
| Hukum Ohm | E = I × R |
| Rata-rata temperatur sumur | (temperatur permukaan + temperatur dasar) / 2 |
| Kapasitas tubing 3-1/2" (pendekatan) | sekitar 110 ft per 1 bbl |
