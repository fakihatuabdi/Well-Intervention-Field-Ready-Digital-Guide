---

| Istilah | Penjelasan |
|---|---|
| **Barrier** | Elemen yang mencegah aliran fluida sumur yang tidak terkendali, misalnya kolom fluida (hidrostatik), BOP, tubing hanger, atau FOSV. |
| **Bleed off** | Membuang tekanan dari sumur atau jalur secara terkendali ke tangki. |
| **Bullhead** | Memompa fluida ke sumur yang tertutup untuk mendorong fluida formasi kembali ke formasi. |
| **Bump Down Job** | Pekerjaan menurunkan plunger untuk mengetuk standing valve atau menyesuaikan spacing tanpa mencabut pompa. |
| **Clean Out Sand** | Membersihkan pasir dari dalam sumur dengan sirkulasi, foam, atau bailing. |
| **Congeal** | Minyak yang mengental atau membeku karena suhu turun di bawah pour point. |
| **Cooling down / initial killing** | Mematikan sumur di awal pekerjaan sampai tekanan nol dan tidak ada aliran. |
| **DIFA** | Pembongkaran dan inspeksi pompa bekas untuk mencari penyebab kegagalan. |
| **Drift** | Diameter minimum yang dijamin bisa dilewati alat di dalam pipa. |
| **Fish** | Benda atau rangkaian yang tertinggal di dalam sumur. |
| **Flow check** | Observasi untuk memastikan tidak ada aliran dari sumur. |
| **Foaming** | Sirkulasi menggunakan foam untuk sumur yang loss agar padatan tetap terangkat. |
| **Gas lock** | Kondisi pompa tidak bisa memompa karena barrel terisi gas. |
| **Hole clean** | Sumur dianggap bersih karena tag mencapai PBTD. Perlu dikonfirmasi dengan temuan rangkaian. |
| **Kick** | Masuknya fluida formasi ke sumur secara tidak terkendali. |
| **Loss circulation** | Fluida yang dipompakan hilang ke formasi sehingga tidak kembali ke permukaan. |
| **Mule shoe** | Ujung tubing yang dipotong miring untuk membantu menembus pasir dan mengarahkan rangkaian. |
| **Overpull** | Tarikan di atas berat rangkaian, dipakai untuk membebaskan rangkaian yang terjepit. |
| **Parted** | Rangkaian rod atau tubing yang patah atau putus. |
| **Premature failure** | Sumur gagal dalam waktu singkat setelah pekerjaan terakhir (misalnya kurang dari 30 hari). |
| **Rabbit** | Alat silinder untuk memastikan ID tubing bisa dilewati alat dengan OD tertentu. |
| **Rat hole** | Jarak antara ujung bawah rangkaian dan dasar sumur. |
| **Repetitive failure** | Sumur yang gagal berulang kali dalam satu tahun (misalnya tiga kali atau lebih). |
| **Reverse circulation** | Sirkulasi dari annulus turun lalu naik melalui tubing. |
| **Scale** | Kerak mineral yang mengendap di dinding pipa dan peralatan. |
| **Screw-in** | Memancing fish dengan menyambungkan kembali ulir rangkaian. |
| **Shut-in** | Menutup sumur menggunakan valve atau BOP. |
| **Slack off** | Menurunkan rangkaian sehingga beban berkurang. |
| **Spacing** | Jarak antara travelling valve dan standing valve saat plunger di posisi terbawah. |
| **Swabbing** | Efek hisap saat rangkaian dicabut cepat, dapat memancing fluida formasi masuk sumur. |
| **Tally** | Catatan panjang tiap joint dan urutan rangkaian. |
| **Tapping** | Travelling valve menabrak standing valve karena spacing terlalu kecil. |
| **Trapped pressure** | Tekanan yang terkurung di dalam sumur atau di bawah sumbatan. |
| **U-tube** | Prinsip keseimbangan kolom fluida di tubing dan annulus. |
| **Unscrew** | Sambungan rod atau tubing yang terlepas di dalam sumur. |
| **Wet pull** | Mencabut tubing yang masih berisi fluida. |
